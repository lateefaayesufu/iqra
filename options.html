Backend Server

Your Iqra backend handles all AI requests securely. The API key lives on the server — never in this extension. Deploy the backend to Vercel and paste your URL here.

e.g. https://iqra-backend-two.vercel.app

✦ How Security Works

  • Your AI API key lives in Vercel environment variables — not in this extension
  • The extension sends only page content to your backend
  • Your backend calls the AI and returns only the summary
  • No secrets are ever stored in or transmitted by the extension
